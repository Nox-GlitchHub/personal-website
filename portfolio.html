Here are some of the web pages I've built while learning. Take a look around

1. Complete Sign-Up Form

This is a Complete Sign-Up registration page from a web project, featuring fields for account creation with specific input rules: a username using alphanumeric characters between 4–12 characters long, a 10-digit phone number, a password at least 8 characters long containing both a letter and number, and a confirm password field to verify the entry. A blue “Create Account” button is provided to submit the form and finalize account registration.

2. Live Character Counter

This is a Live Character Counter web feature from a web development project. It includes a text input area labeled “Enter your message” with a limit of 150 characters, showing a running count of characters used so far. Below it is a Live Preview box that displays typed content in real time, plus a section labeled Character Count that will show the final tally once text is entered. The tool is designed to track, preview, and enforce a character limit as users type.

3. Class Attendance Recorder

This is a Class Attendance web interface for recording student attendance. It features a text field labeled “Enter Fullname” for inputting a student’s name, paired with an “Add Attendance” button to submit the entry. Below, an Attendance List table is structured with columns for numbering, student name, and the time each entry is recorded, providing a clear organized record of attendance submissions.

4. Hogwarts Admission Application

This is a Harry Potter-themed School of Witchcraft & Wizardry admission form with a vintage parchment design. It collects personal details, first magical experience, house preference (Gryffindor, Slytherin, Ravenclaw, Hufflepuff, or Surprise Me), and choice of accompanying creature, with a whimsical SEND BY OWL submission button and magical-themed instructions throughout.

5. Order of the Round Table Registry

This is a medieval Arthurian-themed Order of the Round Table Registry web system for inducting and tracking members. It features a Knightly Oath & Enlistment form where users enter their full name, email, Knight ID, sworn house, rank (Squire or Knight), and personal oath, then submit via SWEAR THE OATH or reset with CLEAR. Below, the Roll of the Order displays all registered members in a structured table listing Knight ID, name, house, contact email, and status — marked as ACTIVE, PENDING, or SQUIRE — plus a notice reminding users to complete all fields before submission.

This is a Hogwarts Student Records web page styled as the school’s official Registrar’s Office. It displays an Autumn Term roster listing students by name, house, year level, house points, and status — marked as Prefect, In Good Standing, or Detention Watch — and is signed by Deputy Headmistress Minerva McGonagall.
